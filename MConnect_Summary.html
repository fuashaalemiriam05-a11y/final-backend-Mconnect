MConnect — Mentorship & Networking Platform

Technical Documentation Summary

1. What the Website Is About

MConnect is a full-stack mentorship and networking platform that connects mentors and mentees. It provides a professional social network experience (similar to LinkedIn) with features such as news feed, direct messaging, group chats, voice calls, stories, mentor profiles with reviews, session scheduling, and an admin dashboard. The platform supports both light and dark themes and is fully responsive on desktop and mobile.

2. Problem Statement

Many students, junior developers, and professionals struggle to find experienced mentors who can guide their career growth. Existing solutions are either informal (LinkedIn DMs, Twitter) or behind paywalls. There is no free, all-in-one platform that combines mentor discovery, messaging, session scheduling, social features (feed, stories, reactions), reviews, and admin oversight.

3. Solution

MConnect provides a unified platform where any user can act as both mentor and mentee. The system uses a unified user role model — no separate tables for mentors/mentees. Features include JWT authentication, real-time messaging, Jitsi-powered voice calls, Prisma ORM with PostgreSQL, and a React + Vite frontend with Tailwind CSS.

5. API Endpoints

The backend runs on Express.js (port 3002). All endpoints return JSON. Protected endpoints require a JWT token (Bearer Auth).

Authentication (/api/auth)

  • POST /signup — Register user. Returns user + JWT token.
  • POST /login — Login. Checks if suspended. Returns user + token.
  • POST /forgot-password — Sends reset email via Ethereal/SMTP. 1hr token expiry.
  • POST /reset-password — Validates token, hashes new password, marks used.

Users (/api/users)

  • GET /me — Get current user profile.
  • GET /mentors — List mentors. Supports ?search, ?expertise, ?minRating.
  • GET /:id — Get user by ID.
  • GET / — List all users (public with optional auth).
  • PATCH /me — Update own profile (name, bio, avatar, expertise).
  • DELETE /me — Delete own account (cascading transaction).
  • PATCH /:id/password — Change password.

Posts (/api/posts)

  • GET / — List posts with author, reactions, comment count, userReaction.
  • POST / — Create post (content, media).
  • GET /:id — Get post detail.
  • DELETE /:id — Delete own post.
  • POST /:id/reactions — Toggle reaction (one per user).
  • GET /:id/comments — Get comments with replies.
  • POST /:id/comments — Add comment (supports parentId for replies).
  • DELETE /comments/:id — Delete own comment.

Conversations & Messages (/api/conversations)

  • GET / — List conversations with last message preview.
  • POST / — Create conversation (direct or group).
  • GET /:id — Get conversation with participants.
  • PATCH /:id — Update group name/icon (multipart).
  • GET /:id/messages — Get all messages (ascending).
  • POST /:id/messages — Send message (text or file: image/voice/document).
  • PATCH /:id/read — Mark messages as read.
  • POST /:id/participants — Add group member.
  • DELETE /:id/participants/:userId — Remove group member.

Stories (/api/stories)

  • GET / — Get non-expired stories (24h), grouped by user.
  • POST / — Create story (media or text).
  • DELETE /:id — Delete story (cascade comments).
  • POST /:id/comments — Add story comment.
  • DELETE /comments/:id — Delete story comment.

Reviews (/api/reviews)

  • GET /mentor/:id — Get reviews for a mentor.
  • POST / — Create review (one per user per mentor).
  • PATCH /:id — Update own review.
  • DELETE /:id — Delete own review. Auto-recalculates mentor rating.

Admin (/api/admin)

  • GET /stats — Platform statistics.
  • GET /activities — Recent activity feed.
  • GET /reports — All reports with reporter + target user.
  • PATCH /reports/:id — Update report status.
  • POST /reports — Submit report.
  • PATCH /users/:id/suspend — Toggle user suspension.
  • DELETE /users/:id — Admin delete user (cascade).

Other

  • /api/mentorship-requests — CRUD mentorship requests.
  • /api/sessions — Manage mentorship sessions.
  • /api/notifications — Get and mark notifications read.
  • /api/uploads — File upload (images, audio, docs, max 25MB).

6. How Components Interact

Architecture: Client-server. Frontend (React + Vite, port 5173) communicates with Backend (Express + Prisma + PostgreSQL, port 3002) via REST API. Vite proxies /api and /uploads to backend.

Frontend: React with component architecture. AuthContext provides user state globally. ThemeContext handles light/dark mode. All API calls go through api() helper which auto-attaches JWT. AppLayout wraps protected routes with DesktopSidebar + BottomNav.

Backend: Express.js with 12 route files. Prisma ORM with 16 database models. JWT authentication. Three middleware levels: authenticate (required), optionalAuth (public), adminOnly.

Example flow — Creating a post:

  1. User types content / selects file on CreatePostScreen
  2. If file, uploadFile() sends to POST /api/uploads → returns server URL
  3. Post + media URL sent to POST /api/posts → creates DB record
  4. SocialFeedScreen fetches GET /api/posts → renders PostCard components
  5. Other users react (one per user), comment, or share

Example flow — Group voice call:

  1. User clicks phone icon in GroupMessageScreen → navigates to /groups/:id/call
  2. GroupCallScreen loads Jitsi Meet API → creates audio-only room: mconnect-voice-{groupId}
  3. Other group members join same room URL — Jitsi handles peer-to-peer audio
  4. Hangup button disposes session and returns to group chat

8. Key Technical Decisions

  • Unified user role: No separate mentor/mentee tables — any user toggles mentor mode by completing their profile.
  • Prisma 7 + adapter-pg: Required for ESM compatibility. Connection string in prisma.config.ts.
  • JWT + optional auth: Public routes (feed, profiles) work without login.
  • Dark mode: CSS custom properties on :root and .dark class, persisted in localStorage.
  • File uploads: multer stores in backend/uploads/, served statically. Vite proxies /uploads.
  • Voice calls: Jitsi Meet external API in audio-only mode. No account required.
  • Password reset: crypto token stored in DB (1hr), sent via Ethereal test emails or SMTP.
  • Account deletion: Prisma transaction cascades — removes all user data atomically.

9. Tech Stack Summary

  • Frontend: React 19, Vite 8, Tailwind CSS 4, React Router, Lucide React icons
  • Backend: Node.js, Express.js, Prisma 7, PostgreSQL 18, JWT, bcrypt, multer, nodemailer
  • External: Jitsi Meet (voice calls), Ethereal (test emails)
  • Auth: JWT (7-day expiry), stored in localStorage
  • Deployment: Vite dev server (port 5173) + Express API (port 3002)
